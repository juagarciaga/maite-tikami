# Maitê Tikami - Website

Maitê Tikami - Odontologia Estética e Implantes | Sua saúde e seu sorriso são a minha missão

## 🦷 About

This is the official website for Maitê Tikami's dental clinic, specializing in aesthetic dentistry and dental implants.

## 🚀 Tech Stack

- **Next.js 16** - React framework for production
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **React 19** - UI library

## 📦 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/juagarciaga/maite-tikami.git
cd maite-tikami
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint
